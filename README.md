# mfeflow starter

A ready-to-use React micro-frontend project: a shell and two remotes on
Module Federation 2.0, with typed API URLs, Google Tag Manager with Consent
Mode v2, OpenTelemetry, lint, tests, CI and a self-hosted registry.

> **Coming with mfeflow v0.1.** This repo is empty until then.

When it is ready you will be able to:

- click **Use this template** on GitHub, or
- run `npx giget gh:mfeflow/starter my-platform`, or
- run `npm create mfeflow@latest my-platform` to pick features yourself.

**Generated, not hand-written.** Every release of
[mfeflow](https://github.com/mfeflow/mfeflow) regenerates this repo with
`npm create mfeflow@latest -- --yes`. To change it, change the templates in
`mfeflow/mfeflow`.
